How Hangul letters join into syllable blocks

Hangul letters are not written in a line like English. They are packed into square blocks, and each block is one syllable. The word 한글 (Hangul) is not six letters in a row; it is two blocks, 한 (han) and 글 (geul), each made of three letters.

This is the one idea that turns a list of letters into reading. Devanagari readers already think this way: कि, कू, क्र are single units built from parts. Hangul does the same thing with stricter geometry.

Every block follows the same rules. It starts with a consonant (the silent ㅇ if there is no consonant sound). Then comes a vowel, to the right if it is a vertical vowel or underneath if it is a horizontal one. It may end with one final consonant (sometimes two) at the bottom, called the batchim. Read every block in the same order: top-left first, then right or down, then the bottom.

Stroke order

Korean is written with two simple rules: left to right and top to bottom. Within a block, write the first consonant, then the vowel, then the final consonant. Within a letter, horizontal strokes go left to right and vertical strokes go top to bottom. The circle ㅇ is drawn anticlockwise from the top. Following the order is not fussiness; it is what makes handwriting fast and readable later.

Try it: write your own name

Break your name into syllables, then build a block for each. Aman is a-man: 아 + 만 = 아만. Neha is ne-ha: 네하. Ravi is ra-bi, because Korean has no v: 라비. Priya needs a helper vowel, since a Korean block cannot begin with two consonants: peu-ri-ya, 프리야. That helper is always ㅡ (eu), which is why "strike" becomes the five-block 스트라이크 (seu-teu-ra-i-keu).

Common mistakes

  • Forgetting the silent ㅇ. A block can never begin with a vowel letter. "a" is 아, not ㅏ.
  • Putting a horizontal vowel beside the consonant. ㅗ, ㅜ, ㅡ always go underneath.
  • Reading a final consonant as a new syllable. 밥 is one beat, "bap", not "ba-pu".
  • Spacing between blocks of one word. Blocks of a word sit together; spaces go between words.
